# SECRET START

↑・↓・←・→・A・B を3回押して START。タイトル画面に隠れた173の世界を集める、日本語のブラウザゲームです。216通りの入力に、173の固有イベントと43の空振りを固定配置しています。

ゲーム本体は TypeScript・Vite・Canvas 2D で実装しています。サーバー側処理、ログイン、データベース、有料API、外部フォントは不要です。

## 起動する

Node.js 22.12 以上を用意し、このフォルダーで実行します。

```powershell
npm ci
npm run dev
```

ブラウザで **http://127.0.0.1:5173/** を開きます。終了するときはターミナルで `Ctrl+C` を押します。

```powershell
npm test                 # データ・状態管理・保存・演出などの自動テスト
npm run build            # 型チェック、本番ビルド、オフライン用キャッシュ生成
node scripts/verify-build.mjs
npm run preview          # 本番ビルドを http://127.0.0.1:4173/ で確認
```

`npm run check` はテストと本番ビルドをまとめて実行します。配布するファイルは `dist/` に生成されます。HTML のダブルクリックではなく、上記のHTTPサーバー経由で遊んでください。

ブラウザで全216入力、画面操作、保存、共有、オフラインを検証する場合は、本番ビルド後に実行します。

```powershell
npx playwright install chromium
npm run test:browser
```

インストール済みの Microsoft Edge を使う場合は、ブラウザ取得の代わりに `$env:PLAYWRIGHT_CHANNEL = 'msedge'` を設定します。画像を含む描画結果と検証ログは `.qa/` に保存されます。[実施済みの結果](docs/test-plan.md)は実機での確認と区別して記載しています。

## 遊び方

画面の6ボタンを3回押して、START で確定します。同じボタンの連続入力もできます。3枠が埋まるまでは START を押せません。

| 操作 | キーボード | 画面操作 |
|---|---|---|
| 3文字を入力 | 矢印キー、A、B | ↑・↓・←・→・A・B |
| START | Enter | START |
| 1文字戻す | Backspace | 入力枠の右の削除ボタン |
| 入力を消す | Delete | 入力をリセット |
| 演出をスキップ | Escape | スキップ |

ミニゲームも同じ6ボタンで遊べます。操作方法とスコアはプレイ中に表示されます。失敗やスキップでも発見は失われません。

| 発見数 | ひらくもの |
|---:|---|
| 5 | ひみつ図鑑：発見済みイベントの検索、カテゴリ絞り込み、お気に入り、再生 |
| 87 | 探索一覧：216通りの未入力・発見済み・空振りを確認し、次の入力をセット |
| 173 | 90秒の真エンディングとコンプリート表示。真エンディングは後から再生可能 |

図鑑は未発見イベントを表示せず、探索一覧も未入力コマンドの結果を明かしません。空振りは試行履歴として残ります。真エンディングは収集173件とは別の追加演出です。

## 保存と設定

発見と入力履歴は、演出が始まる前にブラウザの `localStorage` へ自動保存します。スキップ後も続きから探索できます。

- 設定から記録をJSONへ書き出し、別のブラウザで読み込めます。読み込みは既存の発見・入力履歴・お気に入りと統合します。
- 全消去には2回の確認があります。ブラウザのデータ消去やプライベートモードの終了でも保存は失われるため、持ち運ぶ記録は書き出して保管します。
- 保存できない環境では警告を表示し、開いている画面の中でプレイを続けられます。
- 消音、動きを控えめにする設定、発見済みイベントの自動スキップを用意しています。端末の `prefers-reduced-motion` も反映します。
- X共有は発見数・達成率・ゲームURL入りの投稿画面を開きます。投稿の確定は利用者が行います。

本番ビルドは、すべてのローカルアセットをキャッシュする Service Worker を含みます。HTTPS または localhost で一度読み込み、キャッシュ完了後はオフラインでも探索・図鑑・保存を利用できます。X共有先への接続には通信が必要です。

## 内容と実装

| 種類 | 件数 | 仕様の時間枠 |
|---|---:|---|
| タイトル・日常の変化 | 90 | 2–5秒 |
| 一発ハプニング | 45 | 3–10秒 |
| 短編ストーリー | 20 | 10–30秒 |
| 操作できるミニゲーム | 13 | 30–60秒 |
| 別エンディング | 5 | 60–180秒 |

全173件に固有の日本語台本・時間指定・俳優・小物・配色を設定しています。タイトルと真エンディングには同梱の生成画像を使用し、イベントとミニゲームは共通のピクセル描画パーツで構成しています。画像が読み込めない場合もコード描画で継続します。

```text
src/data/       216コマンド、173イベント、型定義、真エンディング
src/core/       発見・解禁・保存・移行・共有・電子音
src/events/     時間軸の演出、ピクセル描画、13種類のミニゲーム
src/assets/     アセット台帳と読み込み
src/ui/         レスポンシブな画面スタイル
src/main.ts     入力、画面遷移、図鑑、設定の接続
public/assets/  タイトル・真エンディング画像、SVG装飾
tests/          自動テスト
scripts/        オフライン生成、ビルド検証、ブラウザ検証
```

# SECRET START

↑・↓・←・→・A・B を3回押して START。216通りの入力から173の演出を集める、日本語のブラウザーゲームです。

画面にはゲーム機だけを表示します。図鑑、探索一覧、収集記録、設定、管理者モードは、ゲーム機の下部にある5つのボタンからモーダルで開きます。

**[ブラウザーで遊ぶ](https://cadmium2525.github.io/command/)** · [公開リポジトリ](https://github.com/cadmium2525/command)

ゲーム機だけの画面、全演出の管理者プレビュー、読み進めるセリフ、インベーダー風・落ちものブロックに対応した改修版を公開しています。公開先での[検証結果](docs/test-plan.md)も記録しています。

## 起動と確認

Node.js 22.12以上で実行します。

```powershell
npm ci
npm run dev
```

`http://127.0.0.1:5173/` を開きます。終了はターミナルで `Ctrl+C` です。

```powershell
npm test                 # データ、保存、演出、ミニゲームなどの単体テスト
npm run build            # 型チェック、本番ビルド、オフラインキャッシュ生成
npm run verify:build     # 配布物の参照先、容量、Service Workerを検証
npm run preview          # http://127.0.0.1:4173/ で本番ファイルを確認
```

`npm run check` は単体テストとビルドをまとめて実行します。配布物は `dist/` です。HTMLをダブルクリックせず、HTTPサーバー経由で開いてください。

本番ビルド後のブラウザーテストは次のとおりです。

```powershell
npx playwright install chromium
npm run test:browser
```

インストール済みのEdgeを使う場合は、ブラウザー取得の代わりに `$env:PLAYWRIGHT_CHANNEL = 'msedge'` を設定します。検証ログとスクリーンショットは `.qa/` に保存されます。[検証記録](docs/test-plan.md)には今回の画面改修と初版の結果を区別して記載しています。

## 遊び方

6つのボタンから好きなものを3回押し、STARTで確定します。同じボタンの連続入力もできます。入力枠は常に3つで、3文字そろうまでSTARTは無効です。

| 状態 | 操作 | キーボード |
| --- | --- | --- |
| コマンド入力 | ↑・↓・←・→・A・B | 矢印、A、B |
| 実行 | START | Enter |
| 1文字削除 | 入力枠の右の削除ボタン | Backspace |
| 入力を消す | 入力をリセット | Delete |
| 演出の次のセリフへ | A・→・次へ | A・→・Enter |
| 演出の前のセリフへ | B・← | B・← |
| 演出を途中終了 | 左下のスキップ | Escape |
| 読了後に戻る | 読み終えた・戻る／タイトルへ | ボタンを選んでEnter |
| モーダルを閉じる | 右上の閉じる | Escape |

セリフの長さに応じて表示時間を確保し、自動進行も行います。読み進めたいときは「次へ」を押せます。最後のセリフは自動では閉じません。読み終えたら戻るボタンを押してください。「セリフを読み返す」から台本を確認することもできます。

ミニゲーム中は同じ方向キーとA/Bがゲーム操作に変わります。インベーダー風のゲームは左右移動・発射・シールド、落ちものブロックは移動・回転・落下・ハードドロップができます。説明とスコアはゲーム機の中に表示します。

## 管理者モードと収集

管理者モードは初期ONです。図鑑から全173演出を再生でき、探索一覧では全216コマンドの内容を確認できます。管理画面にはインベーダー風、落ちものブロック、真エンディングへの入口もあります。

プレビューで再生しても、実際の発見数・入力履歴・再生済み記録は増えません。タイトルでコマンドを実行した場合は、管理者モード中でも通常どおり発見を記録します。管理者モードはこの端末の閲覧設定で、認証やアクセス制限ではありません。

管理画面の「すべての演出を表示」をOFFにすると、通常の解禁条件へ戻ります。収集記録は保持されます。

| 実際の発見数 | 通常モードでひらくもの |
| ---: | --- |
| 5 | 発見済みだけの図鑑、検索、カテゴリ、お気に入り、再視聴 |
| 87 | 216枠の探索一覧。未入力の演出名・当たり外れは伏せる |
| 173 | 真エンディング。以後は記録モーダルから再視聴できる |

173種類の演出と43種類の空振りは固定配置です。216通りをすべて試せば、乱数や外部サービスに依存せず完集できます。真エンディングは173件の収集対象とは別の追加演出です。

## 保存と設定

発見と入力履歴は、演出開始前にブラウザーの `localStorage` へ保存します。途中でスキップしたり再読み込みしても発見は残ります。

初版からのイベントID・コマンド対応と保存キーを維持しているため、同じ公開URLでは既存の収集記録を引き続き使えます。

- 設定モーダルからJSONを書き出し、別のブラウザーへ読み込めます。読み込みは既存の収集記録と統合します。
- 破損・将来形式の原本は、書き換える前に復旧用の保存先へ退避します。保存不可のときも開いている画面では遊べます。
- 全消去には2段階の確認があり、別タブにも反映します。管理者モードのON/OFFは収集記録とは別に保存します。
- 消音、動きの削減、既読演出の自動スキップを設定できます。端末の `prefers-reduced-motion` も反映します。
- 自動スキップは既読コマンドの再入力に適用します。図鑑と管理者プレビューは再生できます。
- 記録モーダルの共有ボタンは、発見数とゲームURLを含むX投稿画面を開きます。投稿の確定は利用者が行います。

本番ビルドにはService Workerが含まれます。HTTPSまたはlocalhostで初回の読み込みとキャッシュが完了すれば、オフラインでも探索・図鑑・保存を利用できます。

## 実装と資料

TypeScript、Vite、Canvas 2Dで実装しています。サーバー側処理、認証、データベース、有料API、外部フォントは使用しません。描画は320×200の論理キャンバス、操作・日本語のセリフ・モーダルはHTMLです。

収録は日常の変化90件、個別ギャグ45件、物語20件、ミニゲーム13件、特殊エンディング5件です。カタログの分類用尺と、文章を読むための実再生時間は分けています。タイトルと真エンディングには同梱画像を使い、画像を読み込めない場合もコード描画で継続します。

```text
src/data/       216コマンド、173演出、型、真エンディング
src/core/       発見、解禁、保存、移行、共有、電子音
src/events/     読み進める演出、ピクセル描画、13種類のミニゲーム
src/assets/     素材台帳と読み込み
src/ui/         ゲーム機とモーダルの画面スタイル
src/main.ts     入力、管理者プレビュー、モーダル、再生の接続
public/assets/  タイトル・真エンディング画像、SVG
scripts/        キャッシュ生成、配布物検証、ブラウザー検証
```

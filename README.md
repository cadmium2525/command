# SECRET START

↑・↓・←・→・A・Bを3回押してSTART。216通りの入力から173種類のミニゲームを見つける、日本語のブラウザーゲームです。

当たりの入力では必ず操作できるゲームが始まります。プレイ中はルールと操作を表示し、ゲームが終わってからタイトルを明かします。遊んでみるとタイトルの意味がわかる、という流れです。

**[公開サイト](https://cadmium2525.github.io/command/)** · [リポジトリ](https://github.com/cadmium2525/command)

## 起動と確認

Node.js 22.12以上で実行します。

```powershell
npm ci
npm run dev
```

`http://127.0.0.1:5173/`を開きます。終了はターミナルで`Ctrl+C`です。

```powershell
npm test                 # データ、保存、ゲームエンジンなどのテスト
npm run build            # 型チェック、本番ビルド、キャッシュ生成
npm run verify:build     # 配布物の参照先、容量、Service Workerを検証
npm run preview          # http://127.0.0.1:4173/ で本番ファイルを確認
```

`npm run check`はテストとビルドをまとめて実行します。配布物は`dist/`です。HTMLをダブルクリックせず、HTTPサーバー経由で開いてください。

ブラウザー検証には、本番ビルド後に以下を実行します。

```powershell
npx playwright install chromium
npm run test:browser
```

インストール済みのEdgeを使う場合は、ブラウザー取得の代わりに`$env:PLAYWRIGHT_CHANNEL = 'msedge'`を設定できます。検証結果とスクリーンショットは`.qa/`へ保存します。今回の実装の合否は、実際に実行したチェックの出力で確認してください。

## 遊び方

6つのボタンから好きなものを3回押し、STARTで確定します。同じボタンも続けて使えます。3文字そろうまでSTARTは無効です。

| 場面 | 操作 |
| --- | --- |
| コマンド入力 | 方向キーとA/B。キーボードも矢印、A、B |
| 実行 | START、またはEnter |
| 1文字削除 | 削除ボタン、またはBackspace |
| 入力を消す | 入力リセット、またはDelete |
| ゲーム中 | 画面に表示するルールに従い、方向キーとA/Bで操作 |
| 途中終了 | スキップ、またはEscape |
| 結果を読み終えたあと | 戻るボタン |
| モーダルを閉じる | 閉じるボタン、またはEscape |

勝敗が決まるか制限時間に達すると、スコア・結果と、そのゲームのタイトルを表示します。結果は自動で閉じません。読み終えてから、自分で戻れます。勝てなかった場合も、そのゲームの発見は残ります。

画面に置くのはゲーム機だけです。図鑑、探索一覧、記録、設定、管理は、ゲーム機内のボタンからモーダルで開きます。モーダルを開いている間は、ゲームの時間と操作を止めます。

全173件のタイトル、ルール、操作、制限時間、コマンドは[全ゲームカタログ](docs/event-catalog.md)で確認できます。終了時のタイトルを含むため、ネタバレに注意してください。

## 管理者モードと収集

管理者モードは初期ONです。全173件を確認・試遊でき、探索一覧から全216コマンドの対応を調べられます。管理者プレビューで遊んでも、実際の発見数や入力履歴は増えません。ゲーム機でコマンドを実行した場合は、通常の発見として記録します。

管理画面で全表示をOFFにすると、通常の解禁条件へ戻ります。収集記録は保持します。管理者モードは端末の表示設定で、認証による権限管理ではありません。

| 実際の発見数 | 通常モードで開くもの |
| ---: | --- |
| 5 | 発見済みの図鑑、検索、お気に入り、再プレイ |
| 87 | 216枠の探索一覧 |
| 173 | 収集対象とは別の、遊べる完集ボーナス |

173種類の当たりと43種類の空振りは固定です。216通りをすべて試せば、全ゲームを発見できます。勝利や高得点は収集・解禁条件に使いません。

## 保存と互換性

発見と入力履歴は、ゲーム開始前にブラウザーの`localStorage`へ保存します。途中終了や再読み込みをしても発見は残ります。

旧版の173イベントID、216コマンドの対応、保存キーを維持しています。旧版で見つけた項目は、対応する新しいゲームとして引き継ぎます。内部IDに残る`remix`・`gag`・`story`・`ending`は保存互換のための識別子で、現在のゲーム分類ではありません。

設定モーダルからJSONを書き出し、別のブラウザーへ読み込めます。読み込みは既存の記録と統合します。破損したデータや将来形式の原本は、書き換え前に復旧用として退避します。全消去は2段階で確認します。管理者モードは収集記録と別に保存します。

消音と動きの削減に対応し、端末の`prefers-reduced-motion`も反映します。記録モーダルの共有ボタンはXの投稿確認画面を開き、投稿は利用者が確定します。

本番にはService Workerを含みます。HTTPSまたはlocalhostで初回の読み込みとキャッシュが完了すると、オフラインでもゲーム・探索・図鑑・保存を利用できます。

## 実装と資料

TypeScript、Vite、Canvas 2Dで実装しています。ゲームは320×200の論理キャンバスで描画し、ルール、操作ボタン、結果、モーダルはHTMLで表示します。ゲーム本体はローカルのコード描画で動作します。

```text
src/data/                   既存IDとコマンドを維持する173件のカタログ、保存型
src/events/arcade-types.ts   18ジャンルの共通契約、ルールと終了結果の型
src/events/arcade-physical.ts 物理・盤面系92ルールとエンジン
src/events/arcade-skill.ts    操作・判断系81ルールとエンジン
src/events/player.ts         入力、ゲーム時計、描画、終了通知
src/core/                   発見、解禁、保存、移行、共有、音
src/main.ts                 ゲーム機、モーダル、実行と結果表示
scripts/                    キャッシュ生成、配布物とブラウザーの検証
```

## 継続と終了の実動検査

- 落ちものは実操作で4列を消したあとも継続。さらに列を消してレベルが上がること、列数を変えず30秒を越えるだけでも落下間隔が短くなることを検証。
- インベーダーは旧8体のあとも続き、全21体撃破で終了。巨大敵は全HPを削り切って終了。
- ブロック崩しは旧6個のあとも続き、全盤面の破壊で終了。
- 通常スネークの旧エサ数、ラリーの旧返球数、キャッチの旧個数、ランナー・回避の旧時間を越えて継続。無制限モードの失敗と加速も検査。
- 記憶・リズム・入力は新しい問題や小節を生成。通常の操作・判断系73本を正規操作で36～40秒以上継続させ、得点と難度上昇を検証。
- 釣りは65秒後もプレイ状態を維持。バランスの維持秒、釣果、レースの距離、反射の成功数、クリックの旧到達点を越えて継続。
- 迷路は全9variantで出口のあと次面へ進行。滑る迷路の盤面変化、壁破壊の各面3回、3面目からの追跡も確認。
- 全9着陸variantで安全着陸後に燃料を補充し次ステージへ進む。代表では39秒、3ステージ以上を再現。
- 『おやつは３個まで』など固有の短編13本は終了条件を保持。時間上限あり8本はすべて短編ネタに限定。
- 1/3と永久ゴミは消せないマスを保持し、人工的な時間切れに頼らず自然に敗北。
- 手動終了はFINISHとしてタイトルを表示し、自分で戻るまで保持。未終了の通常版は経過時間を表示し、時間制限バーを隠す。

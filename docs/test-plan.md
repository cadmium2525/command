## ブラウザーテストの再現

依存関係と本番ファイルを用意し、インストール済み Edge を使う PowerShell 例です。

```powershell
npm ci
npm run build
$env:PLAYWRIGHT_CHANNEL = 'msedge'
npm run test:browser
Remove-Item Env:PLAYWRIGHT_CHANNEL
```

Edge を使わない環境では Chromium を用意します。

```powershell
npx playwright install chromium
npm run test:browser
```

テストは一時ポートの静的サーバーを起動して終了時に停止し、`.qa` へログとスクリーンショットを書き出します。実際の X 投稿や GitHub Pages への公開は行いません。

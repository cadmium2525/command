## 再現手順

依存関係と本番ビルドを用意し、インストール済みEdgeを使うPowerShellの例です。

```powershell
npm ci
npm run build
$env:PLAYWRIGHT_CHANNEL = 'msedge'
npm run test:browser
Remove-Item Env:PLAYWRIGHT_CHANNEL
```

Chromiumを取得する場合は、代わりに以下を使います。

```powershell
npx playwright install chromium
npm run test:browser
```

公開済みサイトを検証する場合は、対象URLを明示します。ゲーム機内で全入力と記録消去を行うのは、テスト用プロファイルだけです。

```powershell
$env:PLAYWRIGHT_CHANNEL = 'msedge'
$env:BROWSER_TEST_URL = 'https://cadmium2525.github.io/command/'
npm run test:browser
Remove-Item Env:BROWSER_TEST_URL
Remove-Item Env:PLAYWRIGHT_CHANNEL
```

テスト自身はGitHubへのpushや公開を行いません。X Intentは応答を置き換え、実際の投稿はしません。静的サーバーは終了時に停止します。

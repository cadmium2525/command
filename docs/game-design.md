# SECRET START ゲーム設計

## 遊びの核

プレイヤーが操作するのは、↑・↓・←・→・A・B と START のあるタイトル画面です。6種類から3回入力して START を押すと、その組み合わせに対応する小さな世界が開きます。入力の順番は区別し、同じ記号も続けて使えます。216通りの配置は固定で、毎回同じ結果にたどり着けます。

173通りが固有イベント、43通りが空振りです。発見数と試行数を別に扱い、空振りも探索の進展として残します。イベント開始前に発見を保存するため、長い演出をスキップしても収集は進みます。

## 入力から戻るまで

1. タイトルで3文字を入力します。入力中は1文字削除と全入力リセットができます。
2. 3文字がそろうと START が有効になります。試行履歴と新規発見を先に記録します。
3. 短い接続演出のあと、対応する時間軸を再生します。空振りなら静かな画面を表示して戻ります。
4. どのイベントも途中でスキップできます。ミニゲームも成否に関係なく発見済みになります。
5. 終了後は入力を空にしてタイトルへ戻ります。図鑑からの再生後は図鑑へ戻ります。

キーボードは矢印・A・B、Enter で START、Backspace で1文字削除、Delete で全入力削除、Escape で演出スキップです。タッチ・マウス用の画面ボタンも同じ入力経路を使います。設定や検索欄への入力中に、ゲームのショートカットが割り込まないようにしています。

## 内容と時間

| 区分 | 件数 | 仕様枠 | 実装データの範囲 |
|---|---:|---|---|
| ふしぎな日常 `remix` | 90 | 2–5秒 | 2.2–5秒 |
| 一発ハプニング `gag` | 45 | 3–10秒 | 3.5–10秒 |
| ひみつの物語 `story` | 20 | 10–30秒 | 18–30秒 |
| あそべる世界 `minigame` | 13 | 30–60秒 | 30–50秒 |
| もうひとつの結末 `ending` | 5 | 60–180秒 | 60–90秒 |

各イベントは固有の状況と結末を持ち、俳優・小物・配色と、ミリ秒で指定した台本のアクションを組み合わせます。短編は6場面、別エンディングは10場面で進行します。追加の真エンディングは90秒・11場面で、収集173件と216コマンドの外に置いています。

共通パーツは主人公、猫、おばけ、ロボット、スライム、鳥、星、月、魚、箱、タイトル、王冠、植物、ケーキ。6種類の配色と、移動・巨大化・落下・入れ替え・暗転・周回などのアクションを再利用します。台本は単なる色替えや名称変更にせず、行動と展開を個別に記述しています。

全割り当てと台本は [イベントカタログ](event-catalog.md) にまとめています。この資料は結末を含む開発用資料で、ゲーム内の未発見情報には表示しません。

## 13種類のミニゲーム

ミニゲームは固定時間で終了し、プレイ中に操作案内とスコアを表示します。終了時には成否を算出します。スコアはその回の表示用で、収集・解禁条件には使いません。

| 操作方式 | 内容 | 主な操作 |
|---|---|---|
| `catch` | 落ちてくる星を受けとめる | ←→で移動、Aで星へダッシュ |
| `runner` | 横へ流れる障害物をよける | ↑/Aでジャンプ、↓/Bでかがむ |
| `rhythm` | 線に重なった記号を押す | 表示される6ボタンをタイミング入力 |
| `memory` | 最初の4つの光を覚えて再現する | 同じ順番に入力 |
| `balance` | 傾く台を保つ | ←→で調整、Aで安定 |
| `fishing` | 魚の位置に合わせて釣り上げる | ←→で釣り位置、Aで投げる・引く |
| `maze` | 壁を避け、出口へ進む | 矢印、Aでヒント、Bで入口へ |
| `typing` | 6記号のコマンドを順番に修復する | 光っている記号を入力 |
| `invaders` | 降りてくる敵を打つ | ←→で移動、Aで発射、Bでシールド |
| `escape` | 星の目印がある扉を探す | ←→で選択、Aで開く |
| `clicker` | 充電をため、星を灯す | Aで充電、20以上でBを押す |
| `pong` | ボールを打ち返す | ↑↓でラケット、Aで強打、Bで追いつく |
| `choice` | 3つの箱から世界を選ぶ | ←→で選択、Aで開く |

## 解禁と収集

| 発見数 | 変化 |
|---:|---|
| 0–4 | タイトルから自由に入力。進行状況とヒントを表示 |
| 5 | 図鑑が解禁。発見済みを検索・分類・お気に入り登録・再生可能 |
| 87 | 216通りの探索一覧が解禁。未入力／発見済み／空振りを確認可能 |
| 173 | コンプリート表示と90秒の真エンディング。追加演出は繰り返し再生可能 |

図鑑に未発見イベントを並べません。探索一覧は試行履歴を先に参照し、未入力なら結果を伏せます。探索一覧の項目を押すとタイトルの3枠へセットされ、START で確定します。

発見済みイベントを再び入力した場合も通常再生できます。設定で自動スキップを有効にすると、コマンド入力からの再訪だけを省略します。図鑑の再生は設定にかかわらず実行できます。全発見後の終了時には真エンディングへ進み、以降はタイトルと図鑑から見返せます。

## 保存とデータ移行

保存先はブラウザの `localStorage`、キーは `secret-start.save`、現在の形式は `schemaVersion: 2` です。記録するのは試行したコマンド、発見イベント、最後まで見たイベント、お気に入り、設定、全発見演出の案内状態です。同一コマンドを何度試しても重複加算しません。

v1形式の配列名をv2へ移行します。読み込み時は既知のイベント・コマンドだけを採用し、重複や不正値を除きます。破損・保存不可では警告を表示し、画面内の記録を保ってプレイを続けます。

設定からJSONを書き出し、1MB以内のv1/v2の書き出しデータを読み込めます。読み込みは既存の履歴・発見・再生済み・お気に入りを統合し、この端末の設定を維持します。全消去は2段階の確認ダイアログで実行します。

ブラウザや公開URLが変わると保存先も変わるため、移動するときは書き出し／読み込みを使います。保存用サーバーやアカウントは設けていません。

## 表示・音・アクセシビリティ

画面は320×200の論理キャンバスを拡大表示し、操作や日本語字幕はDOMで提供します。画面幅に応じてゲーム機と進行パネルの配置が変わります。ボタンのラベル、キーボード操作、フォーカス表示、字幕の読み上げ通知、進捗表示、確認ダイアログを用意しています。

音は最初の操作後に Web Audio で鳴らす短い電子音です。消音に対応し、画面を離れると音を停止します。音声ファイルのダウンロードは行いません。設定と端末の動きを減らす指定を反映し、揺れ・回転・点滅・装飾の動きを抑えながら、入力と時間の進行を維持します。

## 実装の分担

| ファイル | 責務 |
|---|---|
| `src/main.ts` | 画面遷移、入力、図鑑、探索一覧、設定、再生の接続 |
| `src/data/catalog.ts` | 173件、216入力、固定割り当て、真エンディング |
| `src/data/types.ts` | 入力・台本・保存データの型 |
| `src/core/state.ts` | 発見、解禁、正規化、移行、統合 |
| `src/core/storage.ts` | 自動保存、読み込み失敗への対応 |
| `src/core/audio.ts` / `share.ts` | 電子音、X投稿画面URLの作成 |
| `src/events/player.ts` | 時間軸再生、アクションの描画、終了・破棄 |
| `src/events/minigames.ts` | 13種類の固定ステップ進行、入力、採点、描画 |
| `src/events/art.ts` | 共通ピクセル描画パーツと背景 |
| `src/assets/registry.ts` | 素材ID、パス、利用条件、代替描画 |
| `scripts/build-offline.mjs` | 本番ビルド全体のハッシュとキャッシュ一覧を生成 |

時間軸を描画ループから進め、終了・スキップ・画面遷移時には描画と音を破棄します。見た目の演出と発見記録を分け、演出の途中終了で記録を失わない構成にしています。

## 配信と素材

本番の `dist/` はHTML・JavaScript・CSS・画像・Service Workerからなる静的ファイルです。サーバー側ロジック、課金API、外部アセット、分析サービスを必要としません。GitHub Pages のサブパスと共有先URLはビルド時に設定できます。操作手順と公開状況は [公開手順](deployment.md) を参照してください。

本番ビルド時にローカルファイル全体を列挙し、内容ハッシュで版を付けてオフラインキャッシュを生成します。HTTPS または localhost で初回読み込みとキャッシュ完了後に、オフラインの再読込へ対応します。開発モードでは Service Worker を登録しません。

タイトルには `public/assets/title-world.webp`、真エンディングには `public/assets/ending-world.webp` を同梱しています。画像はローカルから読み込み、失敗時にはコード背景を描画します。ソースと資料はMIT、独自コードアート・SVGはCC0 1.0。2点の生成画像は台帳の `OpenAI-output` 区分で、CC0として再許諾していません。各素材の条件と差し替え口は [素材台帳](assets-manifest.md) にまとめています。

自動テストと実機表示の確認結果は [テスト計画](test-plan.md) を参照してください。

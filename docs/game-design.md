# SECRET START ゲーム設計

## 画面と入力

通常画面に置くのはゲーム機だけです。キャンバス、セリフ、3つの入力枠、方向キー、A/B、START、削除、入力リセットと5つのメニューボタンをゲーム機の中に収めます。外側の見出し、進行パネル、サイトヘッダーやフッターは表示しません。

図鑑、探索、記録、設定、管理の各ボタンはネイティブの `dialog` を開きます。表示中は背景の操作を止め、演出の時間と音も停止します。閉じるボタンとEscapeで元のゲーム機へ戻り、開いたボタンにフォーカスを戻します。ブラウザーの戻る操作でもモーダルを閉じられます。

コマンドは↑・↓・←・→・A・Bから重複を許して3回入力します。3枠が埋まるまでSTARTは無効です。4文字目は保持しません。削除は1文字戻し、リセットは入力だけを空にします。キーボードは矢印、A/B、Enter、Backspace、Deleteに対応します。モーダル内の検索・設定操作にゲームのショートカットは割り込みません。

## 演出の読み進め方

1. 3文字をSTARTで確定し、試行と発見を先に保存します。
2. 短い接続表示の後、対応する演出を再生します。
3. セリフの長さを基準に読む時間を確保して進みます。A・右・STARTで次へ、B・左で前へ進めます。
4. 「セリフを読み返す」は台本モーダルです。開いている間は再生を止めます。
5. 最後はセリフと絵を残し、明示的に「読み終えた・戻る／タイトルへ」を押すまで閉じません。
6. 途中で終了したい場合は左下のスキップ、またはEscapeを使います。発見は失われません。

図鑑・管理者プレビューからの再生は終了後に元のモーダルへ戻ります。通常コマンドからの再生は入力を消してタイトルへ戻ります。空振りも共通反応を表示し、明示的に戻るまで結果を確認できます。

カタログの `durationMs` は分類用の基準尺として保持します。物語の再生時刻は別の読みやすさ用タイムラインから算出し、セリフを読む時間を優先します。ミニゲームは操作時間を変更せず、終了後の結果を読んでから戻ります。

各セリフには最低3秒を確保します。空白を除く文字数を数え、`1000 + 110 × 文字数` ミリ秒を3〜10秒に収めた読書時間と、元の場面間隔の長い方を使います。「次へ」を押せば、この待ち時間を省略できます。

描画は前の場面の位置や登場物を次の場面へ引き継ぎます。字幕と絵の主役・小道具をそろえ、誰が何をしたかをセリフ、登場人物表示、絵で確認できる構成です。

## コマンドと収集

全216コマンドは固定順序で生成します。173種類の固有イベントに1対1で対応し、43コマンドは空振りです。乱数や外部サービスを発見条件に使わず、全216通りを試せば完集できます。

| 種類 | 件数 |
| --- | ---: |
| ふしぎな日常 `remix` | 90 |
| 一発ハプニング `gag` | 45 |
| ひみつの物語 `story` | 20 |
| あそべる世界 `minigame` | 13 |
| もうひとつの結末 `ending` | 5 |

全割り当てと台本は [イベントカタログ](event-catalog.md) にあります。主役、相手や小道具、行動、展開、結末を個別に設定し、単なる配色変更だけで件数を増やしません。真エンディングは173件の外にある追加演出です。

## 管理者プレビューと通常モード

管理者モードは初期ONです。図鑑で全173件を再生し、探索一覧で全216件の結果を確認できます。管理画面にも全演出の一覧、インベーダー風、落ちものブロック、真エンディングへの入口を設けます。

プレビューで未発見イベントを再生しても、発見・入力済み・再生済みの実際の収集記録は更新しません。コマンドを入力して実行した場合は、管理者モードがONでも通常の発見として記録します。実際の発見数は記録モーダルで確認できます。

管理者OFFでは通常の解禁条件を使います。

| 実際の発見数 | 通常モードの変化 |
| ---: | --- |
| 0〜4 | 図鑑と探索一覧は解禁条件を案内 |
| 5 | 発見済みだけの図鑑を解禁 |
| 87 | 216枠の探索一覧を解禁 |
| 173 | 真エンディングを開放し、記録画面から再視聴可能 |

通常の探索一覧は未入力・発見済み・空振りを表示します。未入力の演出名と当たり外れを伏せ、項目を押すとコマンドを3枠へセットします。通常の図鑑は発見済みのみで、検索、カテゴリ、お気に入り、再生を備えます。

管理者設定は `secret-start.admin-preview` に独立して保存します。収集記録を消去してもON/OFFは変えません。この機能は静的サイトの閲覧設定であり、認証・権限による保護機能ではありません。

## 13種類のミニゲーム

ゲーム機の方向キーとA/Bをそのまま操作に使います。スコアと操作案内はセリフ欄に表示し、スコアは収集・解禁条件には使いません。失敗しても発見は保持します。

| 方式 | 内容と主な操作 |
| --- | --- |
| `catch` | 星を受け止める。左右移動、Aでダッシュ |
| `runner` | 障害物をよける。上/Aでジャンプ、下/Bでかがむ |
| `rhythm` | 線に重なる記号をタイミング入力 |
| `memory` | 最初の4つの光を覚えて同じ順序で入力 |
| `balance` | 左右で傾きを調整、Aで安定 |
| `fishing` | 左右で位置を選び、Aで投げる・引く |
| `maze` | 矢印で出口へ進む。Aでヒント、Bで入口 |
| `typing` | 表示された6記号を順番に修復 |
| `invaders` | 敵の編隊・敵弾・残機・ウェーブ。左右移動、Aで発射、Bで再充電式シールド |
| `escape` | 星の目印がある扉を左右で選び、Aで開く |
| `clicker` | Aで充電、20以上でBを押して星を灯す |
| `pong` | 上下でラケット、Aで強打、Bで追いつく |
| `blocks` | 落ちものブロック。左右で移動、上/Aで回転、下で落下、Bでハードドロップ |

インベーダー風は敵に命中すると得点し、敵弾や接近で残機を失います。落ちものは盤面に積み、行がそろうと消えます。どちらもゲームオーバー後は残り時間内にAで再開できます。

## 保存と共有

`secret-start.save` に `schemaVersion: 2` の試行、発見、再生済み、お気に入り、設定、完集案内状態を保存します。発見は再生開始前に確定します。既知のコマンド・イベントだけを採用し、不正値と重複を除き、v1配列名から移行します。

破損・将来形式の原本は `secret-start.save.recovery` へ退避してから新しい値を書きます。退避に失敗した場合は原本を保持し、画面内でプレイを続けます。別タブの発見は統合し、明示的な全消去は別タブにも反映します。

設定から1MB以内のJSONを読み込み、既存の発見・試行・再生済み・お気に入りと統合します。書き出しはJSONダウンロードです。全消去は2段階の確認を使います。

消音、動きの削減、既読コマンドの自動スキップを設定できます。図鑑と管理者プレビューは自動スキップの対象外です。X共有は記録モーダルのリンクから、明示操作で本文と公開URLを含むWeb Intentを開きます。自動投稿や投稿成功表示は行いません。

## 表示と配信

320×200の論理キャンバスをピクセル単位で拡大し、セリフと操作はHTMLで表示します。幅320pxから横画面まで、必要に応じたスクロールで操作へ到達できます。ボタンラベル、フォーカス表示、読み上げ通知、進捗表示、ネイティブモーダルを使用します。

音声は最初の操作以降にWeb Audioで鳴らし、消音・画面離脱・モーダル閲覧時には停止します。設定とOSの動き削減指定を反映します。外部フォント、分析サービス、サーバー、DB、認証、課金APIを必要としません。

本番ファイルは `dist/` です。ビルド時に全ローカルファイルのハッシュと事前キャッシュを生成し、HTTPSまたはlocalhostで初回読み込み後のオフライン再読み込みに対応します。GitHub Pagesのbaseと共有URLはビルド時に設定できます。

素材IDとパスは `src/assets/registry.ts` に集約します。コードアート、SVG、タイトル・真エンディングの同梱画像を使い、画像を読み込めない場合はコード背景へ戻ります。条件は [素材台帳](assets-manifest.md)、配信手順は [公開手順](deployment.md)、今回の実施結果は [検証記録](test-plan.md) を参照してください。

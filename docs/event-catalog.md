# SECRET START — 全173ゲームカタログ

この資料は結果で明かす全タイトルを掲載する、開発用のネタバレ資料です。`src/data/catalog.ts`が直接参照する`PHYSICAL_DEFINITIONS`と`SKILL_DEFINITIONS`のexport結果から生成しています。ゲーム内の図鑑は5種類の発見で開き、発見済みの項目だけを表示します。

173個の当たりコマンドは、すべて操作できるゲームです。プレイ中は課題と操作を表示し、終了後にタイトルを明かします。発見は開始時に記録し、勝敗と発見判定は独立しています。結果は自動で閉じず、戻る操作を待ちます。

通常ゲームに一律の20秒・30秒の終了はありません。`durationMs: 0`は時間制限なしを表します。落ちもの・ラリー・回避などはゲームオーバーまで、記憶・入力・迷路・着陸などは次の問題やステージへ進みながら遊べます。敵の全滅やブロック全破壊で終了する盤面クリア型もあります。数回で終わる固有ルールは、その課題自体をタイトルのオチにしたものです。

入力記号は`U = ↑`, `D = ↓`, `L = ←`, `R = →`, `A`, `B`。全216通りのうち173通りをゲームへ固定配置し、43通りは空振りです。内部IDの旧接頭辞は保存互換用の住所で、現在のジャンル名ではありません。旧版のIDとコマンド対応を維持しています。

## 完集ボーナス — 専用アーケード・リミックス

内部IDは`true-ending`。173種類目のゲームを終えてタイトルへ戻ると、初回だけ自動で始まります。以後は記録モーダルから遊べます。コマンドと収集枠を消費せず、勝利も必要ありません。`COMPLETION_DEFINITION`を直接参照する専用エンジンです。

- 結果タイトル：**173の先のアーケード**
- 開始時の説明：全173種類、発見おめでとう！ 5つのゲームを交代で遊ぶボーナス。共通ライフ3で、何周できるか挑戦しよう。
- 循環するゲーム：落ちもの → シューティング → スネーク → ブロック崩し → ランナー → 最初へ。
- 共通ライフ3。ミスで1減り、なくなるまで継続。各ゲーム内の残機減少も共通ライフのミスとして扱います。
- 交代時は新しいジャンルと操作を示して2秒準備。0.65秒以上待ってAを押すと早めに始められます。
- 各セクションは最初14秒。時間が来ても全体は終了せず、次のゲームへ交代します。クリアも次のゲームへ進みます。
- 得点を持ち越し、生存交代は10点、クリアは50点を加算。周回ごとに速度を上げ、セクションを8秒まで短くします。
- 全体の時間制限はありません。ライフ切れか手動終了のあとに、結果タイトルを表示します。

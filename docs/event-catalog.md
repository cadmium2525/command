# SECRET START — 全イベントカタログ

`src/data/catalog.ts` の実データから生成した、全173件と追加の真エンディングの台本です。字幕は、画面に登場する主人公・相手・小物の目的と動きを短い文で説明します。画面にない駅・手紙・雲・店などを、別の物語として語る方式は使いません。

入力記号は `U = ↑`, `D = ↓`, `L = ←`, `R = →`, `A`, `B`。全216通りのうち173通りを固定の演出へ割り当て、43通りをハズレとしています。IDとコマンドの組み合わせは変更していません。真エンディングは173件すべての発見後に開く追加演出で、収集枠を消費しません。

| 区分 | 件数 | 設計上の時間 | 字幕を読める実再生時間 |
|---|---:|---|---|
| ふしぎな日常 (remix) | 90 | 2.2秒–5秒 | 9.09秒–10.7秒 |
| 一発ハプニング (gag) | 45 | 3.5秒–10秒 | 9.62秒–13.54秒 |
| ひみつの物語 (story) | 20 | 18秒–30秒 | 21.18秒–31.8秒 |
| あそべる世界 (minigame) | 13 | 30秒–50秒 | 30秒–50秒 |
| もうひとつの結末 (ending) | 5 | 60秒–90秒 | 60.02秒–90秒 |

通常演出では、各字幕を最低2.5秒、文字数に応じて最大8秒確保します。もとの字幕間隔が長い場合は、その間隔を保ちます。再生中の「次へ」で読み終えた字幕を進められます。最後の字幕と画面は残り、「戻る」を押すまでタイトル画面へ戻りません。ミニゲームは30–50秒のゲーム時計で進行し、終了後の結果も手動で戻るまで残ります。スキップは可能です。

画面の人物・小物には名前を表示します。使用する14種類は、主人公 (`hero`)、猫 (`cat`)、おばけ (`ghost`)、ロボット (`robot`)、スライム (`slime`)、鳥 (`bird`)、星 (`star`)、月 (`moon`)、魚 (`fish`)、箱 (`box`)、看板 (`title`)、王冠 (`crown`)、植木 (`plant`)、ケーキ (`cake`)です。大きくなる・縮むのは主役で、降る物・積む物・引く物・列車の荷物は小物欄の実際の絵です。氷に閉じ込められる、箱などの後ろに隠れる、眠るといった状態は、次の字幕でも続きます。`reveal` で氷・暗さ・隠れ・睡眠を解除します。

各表の時刻は、字幕を読む時間を加えた実再生開始からの秒数です。手動で「次へ」を使った場合は短くなります。設計時間は互換性のため維持した元データ、字幕込み時間は現在の再生ロジックで算出した時間です。

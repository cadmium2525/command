# SECRET START — 全173ゲームカタログ

この資料は終了後に明かす全タイトルを掲載する、開発・管理者向けのネタバレ資料です。エンジンが持つタイトル・課題・操作・制限時間から生成しています。

当たり173コマンドはすべてミニゲームです。プレイ中は課題と操作を表示し、終了後にタイトルを明かします。結果は自分で戻るまで残ります。負けても発見として記録され、管理者プレビューは収集記録を変えません。

全216コマンドのうち43件は空振りです。旧版の173内部IDとコマンド割り当てを維持して、以前の保存記録を引き継ぎます。IDの接頭辞は現在のジャンルを表しません。
